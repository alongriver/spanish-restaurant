# Sol y Sombra · 西班牙风味餐厅主页

一个单文件、自包含的西班牙风味餐厅官网示例页面，纯 HTML / CSS / 原生 JavaScript 实现，无构建步骤，双击 `index.html` 即可打开。

## 特性

- 全屏 Hero 主视觉 + 品牌故事 + 招牌菜品 + 菜单精选 + 餐厅空间 + 预订表单
- 深炭棕 × 藏红花金 × 陶土红的西班牙暖调配色
- 响应式布局：桌面 / 平板 / 手机自适应，移动端抽屉式导航
- 全部图片为 AI 生成的美食与环境素材，存放于 `assets/`
- 预订表单含提交反馈（toast），页面底部标注为示例数据

## 目录结构

```
spanish-restaurant/
├── index.html      # 唯一入口页面
└── assets/         # 图片素材（hero / paella / tapas / interior / sangria / jamon）
```

## 说明

本页面为示例站点，餐厅地址、电话与菜品价格均为虚构数据。
